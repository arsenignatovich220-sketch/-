# <h3 align="center"> Тема: “Знайомство з базовими командами CLI-режиму в Linux”
### Мета роботи:
- Знайомство з базовими командами CLI-режиму в Linux.
- Знайомство з базовими текстовими командами в термінальному режимі роботи в різних ОС.
### Словник термінів:
- Command Line Interface (CLI) — інтерфейс командного рядка; інструмент, який забезпечує точний контроль, високу швидкість роботи та можливість легко автоматизувати завдання за допомогою скриптів.
- Shell — оболонка (інтерпретатор командного рядка); програма, яка приймає введені користувачем команди та перекладає їх у дії, які має виконати операційна система.
- Bash shell — найпопулярніша оболонка у дистрибутивах Linux, яка має такі функції, як історія команд, вбудоване редагування, підтримка скриптів, аліасів та змінних.
- Prompt — запрошення командного рядка; важлива частина інтерфейсу, яка з'являється під час запуску термінала й зазвичай містить інформацію про користувача та систему (наприклад, ім'я користувача, назву системи та поточний каталог).
- Home directory () — домашній каталог особиста папка користувача, яка в Linux позначається символом тильди () і зазвичай розташована за шляхом /home/ім'я_користувача.
- Case-sensitivity — чутливість до регістру; властивість системи Linux, яка вимагає вводити команди, опції, аргументи, змінні та назви файлів з точним дотриманням великих і малих літер.
- Command — команда; програмне забезпечення (утиліта), яке при виконанні в CLI виконує певну дію на комп'ютері.
- Options — опції (або ключі); використовуються для зміни базової поведінки команди. Однолітерні опції починаються з одного дефіса (-), а повні слова — з двох дефісів (--).
- Arguments — аргументи; використовуються для надання додаткової інформації команді (наприклад, імені файлу або користувача), тобто вказують, над чим саме команда має виконати дію.
- Internal commands (built-in) — внутрішні (вбудовані) команди; команди, які є невіддільною частиною самої командної оболонки.
- External commands — зовнішні команди; команди, які зберігаються в окремих файлах на диску, які оболонка шукає під час виклику.
- Aliases — аліаси (псевдоніми); короткі назви (нікнейми), які створюються користувачем для заміни довших і складніших команд.
- Functions — функції; створені на основі вже наявних команд нові команди, які можуть розширювати або перевизначати поведінку вбудованих чи зовнішніх команд.
- Variables — змінні; функція, яка дозволяє користувачеві або оболонці тимчасово зберігати дані в пам'яті для надання системної інформації чи зміни поведінки Bash. Поділяються на локальні (local) та змінні оточення (environment).
### Завдання для попередньої підготовки:
#### Командний інтерпретатор (англ. Command interpreter) — це спеціальна програма, яка приймає введені користувачем текстові команди з клавіатури, аналізує (інтерпретує) їхній синтаксис і перекладає у конкретні дії чи системні виклики, які здатна виконати операційна система.
#### Оболонка (англ. Shell) — це безпосередньо сам інтерфейс користувача (у даному контексті — текстовий командний інтерпретатор, як-от Bash), який виступає «оболонкою» навколо ядра операційної системи. Вона захищає ядро від прямого втручання та надає користувачеві зручний спосіб взаємодії з комп'ютером через командний рядок.
#### Команда (англ. Command) — це окрема комп'ютерна програма, утиліта або вбудована інструкція, яка при введенні та виконанні в командному рядку запускає певне програмне забезпечення для виконання конкретної дії на комп'ютері (наприклад, виведення списку файлів, копіювання чи створення папки).
#### Базова інформація рядка запрошення (prompt):
Зазвичай prompt містить три основні елементи: ім'я користувача (username), назву системи/комп'ютера (hostname) та поточний робочий каталог (де символ ~ означає домашню директорію).
#### Призначення параметрів (опцій) та аргументів:
- Параметри (опцій) потрібні для того, щоб змінити або розширити базову поведінку команди (наприклад, змінити формат виведення даних).
-  Аргументи потрібні для того, щоб надати команді додаткову інформацію для роботи — тобто вказати конкретний об'єкт (файл, директорію, текст), над яким потрібно виконати дію.
#### Призначення, параметри та аргументи команди ls:
Команда ls призначена для виведення списку вмісту директорії. Як аргумент вона приймає шлях до папки, а як параметри — ключі на кшталт -l (довгий формат з деталями), -a (показувати приховані файли) чи -r (зворотний порядок).
- Приклад 1: ls /etc — виведе вміст папки /etc у стандартному вигляді (використано аргумент).
- Приклад 2: ls -l — виведе вміст поточної папки у вигляді детального списку з правами доступу та розміром файлів (використано параметр).
- Приклад 3: ls -la /var — виведе абсолютно всі файли (включаючи приховані) у папці /var у вигляді детального списку (поєднано параметри та аргумент).
#### Використання історії команд та її переваги:
Історію команд можна викликати за допомогою клавіш «Стрілка вгору» / «Стрілка вниз» на клавіатурі або командою history. Це дає змогу швидко знаходити, редагувати та повторно запускати раніше введені команди, що значно економить час і позбавляє від необхідності вводити довгі конструкції вручну.
#### Призначення команди echo:
Команда echo призначена для виведення рядка тексту або значень змінних у термінал (стандартний вивід).
#### Поняття змінної в Bash та її типи:
Змінна в Bash — це іменована область пам'яті, яка дозволяє користувачеві або самій оболонці тимчасово зберігати дані для подальшого використання. Вона підтримує два основні типи змінних:
- Локальні (local) — доступні лише всередині поточного екземпляра оболонки (сесії) або скрипту, де вони були створені.
- Змінні оточення (environment) — глобальні змінні, які передаються всім дочірнім процесам та програмам, що запускаються з цієї оболонки.
#### Призначення команд env, export та unset:
- env — виводить список усіх поточних змінних оточення (або запускає програму в зміненому середовищі).
- export — експортує (переводить) локальну змінну у статус змінної оточення, роблячи її доступною для інших програм у цій сесії.
- unset — видаляє (анулює) змінну або функцію з пам'яті оболонки.
#### Команди для отримання довідки в терміналі:
-  man [назва_команди] — відкриває детальне офіційне керівництво (manual page).
- help [назва_команди] — надає довідку для вбудованих (internal) команд Bash.
- [назва_команди] --help (або -h) — стандартний параметр для виклику короткої довідки безпосередньо від самої утиліти.

### Контрольні запитання:
#### 1.Які типи команд існують в оболонці Bash?
В оболонці Bash усі команди поділяються на 4 основні типи:
- Вбудовані команди (Builtins): Частина самого коду оболонки Bash. Вони виконуються миттєво в поточному процесі (наприклад: cd, echo, pwd, alias).
- Зовнішні команди (External commands): Окремі програми (бінарні файли чи скрипти), які зберігаються на диску в системних директоріях. Для їх виконання Bash створює окремий процес (наприклад: ls, mkdir, uname, cal).
- Псевдоніми (Aliases): Створені користувачем скорочення або ярлики для інших команд чи послідовностей команд (наприклад: створений вами mycal1).
- Функції (Functions): Блоки коду, написані мовою Bash, які зберігаються в пам'яті оболонки та виконуються під одним ім'ям (наприклад: створена вами students_report).
#### 2. Що таке змінні оточення? Які вони бувають. Як їх можна переглянути в терміналі?
Змінні оточення (Environment Variables) — це глобальні іменовані змінні системи, які зберігають конфігураційні дані та доступні для самої оболонки Bash, а також для всіх програм і процесів, які з неї запускаються.
Які вони бувають (типи змінних у Linux):
-  Локальні змінні: Доступні лише в поточній сесії конкретного термінала і не передаються програмам, які з нього запускаються.
-   Глобальні (змінні оточення): Доступні поточному терміналу та всім його дочірнім процесам/програмам (створюються за допомогою команди export).
###### Як їх переглянути в терміналі:
- printenv або env — виводить список усіх глобальних змінних оточення [Варіант 1].
- set — виводить взагалі всі змінні (і локальні, і глобальні), а також функції Bash.
- echo $НАЗВА_ЗМІННОЇ — виводить значення однієї конкретної змінної (наприклад: echo $PATH) [Варіант 1].
#### 3.Опишіть змінну $PS1. Як в терміналі переглянути її вміст?
Змінна $PS1 (Prompt String 1) — це головна змінна оточення, яка визначає зовнішній вигляд ряду запрошення (prompt) командного рядка Bash (текст, який ви бачите ліворуч від курсору перед введенням кожної команди). Вона складається зі спеціальних керуючих символів (наприклад, \u для імені користувача, \h для хоста, \w для поточної директорії).
###### Як переглянути її вміст:
- echo $PS1
#### 4.Як можна змінити значення змінної $PS1? Що при цьому відбудеться в рядку запрошенні в bash? Як змінити значення цієї змінної не на поточний сеанс, а за замовчуванням?
Як змінити на поточний сеанс:
Потрібно просто присвоїти їй нове значення в терміналі:
- PS1="my-terminal> "
###### Що при цьому відбудеться:
Одразу після натискання Enter стандартний вигляд рядка запрошення зникне, і замість нього перед курсором завжди буде писатися текст my-terminal> .
###### Як змінити за замовчуванням (назавжди):
Щоб налаштування не зникали після закриття термінала, рядок із присвоєнням змінної потрібно записати в прихований конфігураційний файл домашньої директорії користувача — .bashrc (або .bash_profile).
#### 5.Для чого використовують лапки в оболонці Bash?
Лапки використовуються для екранування та групування тексту:
- Одинарні лапки (' '): Повністю вимикають дію всіх спеціальних символів оболонки (метасимволів) . Все всередині них сприймається системою як звичайний текст (наприклад, '\$var' виведеться текстом, а не значенням змінної) .
- Подвійні лапки (" "): Захищають текст від розділення на окремі аргументи через пробіли, але дозволяють роботу спецсимволів долара (\() для підстановки змінних та зворотних лапок (` або \)()) для виконання команд всередині рядка .
- Зворотні лапки (` `): Використовуються для підстановки результату команди (Command Substitution) . Оболонка спочатку виконує команду всередині цих лапок, а потім підставляє її результат замість них .
#### 6.Для чого використовують інструкції керування, які їх види Ви знаєте?
Інструкції керування (Control Statements) використовуються для автоматизації рутинних завдань і керування логікою виконання команд. Вони дозволяють комп'ютеру приймати рішення або повторювати певні дії без втручання людини.
Види інструкцій керування:
###### Умовні оператори (Розгалуження): Дозволяють виконувати команди лише тоді, коли виконується певна умова.
	- if ... then ... else ... fi
	- case ... in ... esac
###### Цикли: Дозволяють повторювати блок команд певну кількість разів або поки виконується умова.
	- for — цикл із переліком значень (використовувався у нашому завданні).
	- while — цикл, що виконується, поки умова істинна.
	- until — цикл, що виконується, поки умова залишається хибною.
#### 8.Яке призначення команд whereis та locate? Яка між ними відмінність?
Обидві команди призначені для пошуку файлів, але вони шукають різні речі та за різними принципами .
- whereis — шукає виключно бінарні (виконувані) файли програм, їхні вихідні коди та відповідні їм сторінки системної довідки man . Вона обмежена пошуком лише в стандартних системних папках (наприклад, /bin, /sbin, /usr/share/man).
- locate — це команда загального пошуку будь-яких файлів на всьоому диску за назвою. Вона працює миттєво, тому що шукає файли не скануючи весь жорсткий диск в реальному часі, а звертаючись до спеціальної заздалегідь створеної бази даних системи (/var/lib/mlocate).
