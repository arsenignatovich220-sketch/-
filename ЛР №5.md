### Мета роботи:
- Отримання практичних навиків роботи з командною оболонкою Bash.
- Знайомство з базовими командами навігації по файловій системі.
- Знайомство з базовими командами для керування файлами та каталогами.
### Словник термінів:
- File — файл (використовується для зберігання даних, таких як текст, графічні зображення та програми)
- Directory — каталог / папка (тип файлу, який використовується для зберігання інших файлів та забезпечення ієрархічної структури)
- Filesystem — файлова система (організаційна структура каталогів та файлів у системі)
- Root directory — кореневий каталог (найвищий рівень віртуальної файлової системи в Linux, що позначається символом /)
- CLI (Command Line Interface) — інтерфейс командного рядка (текстовий спосіб взаємодії з операційною системою за допомогою команд)
- GUI (Graphical User Interface) — графічний інтерфейс користувача (візуальне середовище з вікнами та іконками для керування файлами)
- Globbing — глобінг (використання символів-шаблонів, або «вайлдкардів», для пошуку та маніпуляцій із групами файлів за певною маскою)
- Wildcards — символи підстановки / маски (спеціальні символи на кшталт * або ?, які інтерпретуються оболонкою (shell) для відповідності іменам файлів)
- cd (change directory) — команда зміни каталогу (використовується для переміщення між каталогами у командному рядку)
- cp (copy) — команда копіювання (використовується для створення копій файлів або каталогів)
- mv (move) — команда переміщення / перейменування (використовується для переміщення файлу в інше місце або зміни його імені)
- rm (remove) — команда видалення (використовується для видалення файлів або каталогів)
- rmdir — команда видалення каталогу (використовується для видалення виключно порожніх каталогів)
- mkdir (make directory) — команда створення каталогу (використовується для створення нового каталогу)
- touch — команда створення порожнього файлу (використовується для створення нового файлу розміром 0 байтів)
- FHS (Filesystem Hierarchy Standard) — Стандарт ієрархії файлової системи (набір правил, що визначає загальні назви та призначення каталогів у дистрибутивах Linux).

##### 2.Що таке FHS та як цей стандарт використовується?
FHS (Filesystem Hierarchy Standard — Стандарт ієрархії файлової системи) — це офіційний документ, який регламентує розміщення каталогів та файлів певного типу в Linux-системах.
##### Роль стандарту в контексті файлових систем:
- Уніфікація: Завдяки FHS розробники ПЗ та системні адміністратори завжди знають, де шукати конфігурації, бінарні файли чи логи, незалежно від дистрибутива (Ubuntu, Fedora, Arch тощо).
- Прогнозованість: Забезпечує сумісність програм. Програми інсталюються у чітко визначені місця.
- Поділ даних: FHS чітко розділяє файли на статичні (що не змінюються без адміністратора, як-от /usr) та динамічні (що постійно змінюються, як-от /var).
##### Ключові каталоги згідно з FHS:
- /bin — основні утиліти командного рядка, необхідні для всіх користувачів.
- /boot — файли, необхідні для завантаження системи (ядро, інсталятор Grub).
- /etc — конфігураційні файли системи та програм.
- /home — особисті каталоги користувачів із їхніми даними та налаштуваннями.
- /var — змінні дані: логи (/var/log), бази даних, черги принтерів.
##### 3.Основні команди Linux для роботи з файлами та каталогами
- Створення
   - touch назва_файлу — створити порожній файл.
	- mkdir назва_папки — створити новий каталог.
- Переміщення та перейменування
   - mv шлях_звідки шлях_куди — перемістити файл або каталог.
	- mv старе_ім'я нове_ім'я — перейменувати файл або каталог.
- Копіювання
   - cp файл_джерело файл_копія — скопіювати файл.
	- cp -r папка_джерело папка_копія — скопіювати каталог разом із вмістом (рекурсивно).
- Видалення
  - rm назва_файлу — видалити файл.
  - rmdir назва_папки — видалити порожній каталог.
  - rm -rf назва_папки — видалити каталог з усім його вмістом без попереджень (використовувати обережно).

#### 2.Таблиця опису команд:
| Назва команди | Її призначення та функціональність |
| :--- | :--- |
| pwd | Визначає місце знаходження користувача у файловій системі, показує поточну робочу директорію (print working directory) |
| cd Documents | Команда cd здійснює перехід до каталогу, який у неї вказаний як аргумент. В даному випадку це каталог Documents |
| cd / | Перехід до кореневого каталогу (/) файлової системи (абсолютний шлях). |
| cd ~ або cd | Повернення до домашнього каталогу поточного користувача (символ ~ є сервісним скороченням для $HOME). |
| cd .. | Перехід на один рівень вгору до батьківського каталогу відносно поточного. |
| cd . | Залишається в поточному каталозі (символ . позначає поточну директорію; використовується для побудови відносних шляхів). |
| ls | Виводить список вмісту (файлів та підкаталогів) поточної або вказаної директорії. |
| ls -a | Відображає всі файли, включаючи приховані файли та каталоги, назва яких починається з крапки (.). |
| ls -l | Довгий (детальний) формат виведення. Показує права доступу, кількість жорстких посилань, власника, групу, розмір у байтах та час останньої модифікації. |
| ls -h | Виводить розмір файлів у зручному для читання форматі (Human-readable: Кб, Мб, Гб) разом із прапорцем -l. |
| ls -S | Сортує вміст за розміром (від найбільшого до найменшого). |
| ls -t | Сортує вміст за часом модифікації (спочатку новіші). |
| ls -R | Рекурсивне виведення. Показує вміст поточної директорії та всіх її підкаталогів. |
| cp source_file dest_file | Копіює файл або файли з джерела (source_file) у місце призначення (dest_file). |
| cp -r source_dir dest_dir | Рекурсивне копіювання. Використовується для копіювання каталогів разом з усім їхнім вмістом. |
| cp -i source dest | Інтерактивний режим. Запитує підтвердження перед перезаписом файлу, якщо такий уже існує в цільовому каталозі. |
| cp -p source dest | Зберігає властивості файлу (Preserve). Копіює файл, зберігаючи оригінальні часові мітки, права доступу та власника. |
| mv old_name new_name | Перейменовує файл або каталог, якщо переміщення відбувається в межах однієї директорії. |
| mv file_name directory/ | Переміщує файл або каталог у вказане місце призначення. |
| mv -i source dest | Інтерактивний режим. Запитує підтвердження перед перезаписом файлу під час переміщення. |
| mv -n source dest | Забороняє перезапис. Не переміщує та не перезаписує існуючий цільовий файл (no-clobber). |
| touch new_file | Створює новий порожній файл. Якщо файл уже існує, команда просто оновлює його часову мітку (дата й час останньої модифікації). |
| mkdir new_directory | Створює новий порожній каталог (директорію) із вказаним ім'ям у поточному місці. |

### Контрольні запитання:
##### 1. Перегляд шляху до домашньої директорії через echo (2 способи)
- Спосіб 1:
  - echo $HOME
- Спосіб 2:
  - echo ~
##### 2. Перегляд вмісту кореневого каталогу без переходу в нього
Так, це можна зробити. Команда ls приймає шлях до каталогу як аргумент. Перебуваючи в домашньому каталозі, достатньо просто вказати корінь (/) цільовим об'єктом для перегляду:
- ls /
##### 3. Додавання інформації в порожній файл
- echo "Ваш текст" > назва_файлу
##### 4.Копіювання та видалення каталогів (різниця для порожніх/непорожніх):
- Копіювання каталогу:
Незалежно від того, порожній каталог чи ні, для його копіювання команда cp обов'язково вимагає рекурсивний ключ -r:
  - cp -r каталог_джерело каталог_призначення
- Видалення каталогу:
  - Якщо каталог порожній: Можна використати спеціальну команду rmdir каталог або загальну rm -r каталог.
  - Якщо каталог НЕ порожній: Команда rmdir видасть помилку. Застосовувати можна виключно команду rm з рекурсивним ключем:
  - rm -r назва_каталогу
##### 5.Аналіз прикладів з командою mv
Команда mv діє залежно від вказаних шляхів та кінцевих імен:
- mv /work/tech/comp.png /Desktop
  - Дія: Чисте переміщення файлу. Файл переноситься в іншу директорію (/Desktop), але зберігає своє оригінальне ім'я comp.png. (Примітка: крапка після розширення у вашому прикладі, ймовірно, є оддруком).
- mv /work/tech/comp.png /work/tech/my_car.png
   - Дія: Чисте перейменування файлу. Файл залишається в тому самому каталозі (/work/tech/), але його назва змінюється з comp.png на my_car.png.
- mv /work/tech/comp.png /Desktop/computer.png
   - Дія: Одночасно дві дії (переміщення + перейменування). Файл переноситься в абсолютно новий каталог (/Desktop) і водночас отримує нове ім'я computer.png.
