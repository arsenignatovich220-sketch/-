# <h3 align="center"> Тема: “Знайомство з командами навігації по файловій системі та керування файлами та каталогами”
### Мета роботи:
- Отримання практичних навиків роботи з командною оболонкою Bash.
- Знайомство з базовими командами навігації по файловій системі.
- Знайомство з базовими командами для керування файлами та каталогами.
### Словник термінів:
- File — файл (використовується для зберігання даних, таких як текст, графічні зображення та програми)
- Directory — каталог / папка (тип файлу, який використовується для зберігання інших файлів та забезпечення ієрархічної структури)
- Filesystem — файлова система (організаційна структура каталогів та файлів у системі)
- Root directory — кореневий каталог (найвищий рівень віртуальної файлової системи в Linux, що позначається символом /)
- CLI (Command Line Interface) — інтерфейс командного рядка (текстовий спосіб взаємодії з операційною системою за допомогою команд)
- GUI (Graphical User Interface) — графічний інтерфейс користувача (візуальне середовище з вікнами та іконками для керування файлами)
- Globbing — глобінг (використання символів-шаблонів, або «вайлдкардів», для пошуку та маніпуляцій із групами файлів за певною маскою)
- Wildcards — символи підстановки / маски (спеціальні символи на кшталт * або ?, які інтерпретуються оболонкою (shell) для відповідності іменам файлів)
- cd (change directory) — команда зміни каталогу (використовується для переміщення між каталогами у командному рядку)
- cp (copy) — команда копіювання (використовується для створення копій файлів або каталогів)
- mv (move) — команда переміщення / перейменування (використовується для переміщення файлу в інше місце або зміни його імені)
- rm (remove) — команда видалення (використовується для видалення файлів або каталогів)
- rmdir — команда видалення каталогу (використовується для видалення виключно порожніх каталогів)
- mkdir (make directory) — команда створення каталогу (використовується для створення нового каталогу)
- touch — команда створення порожнього файлу (використовується для створення нового файлу розміром 0 байтів)
- FHS (Filesystem Hierarchy Standard) — Стандарт ієрархії файлової системи (набір правил, що визначає загальні назви та призначення каталогів у дистрибутивах Linux).
### Завдання для попередньої підготовки:

##### 2.Що таке FHS та як цей стандарт використовується?
FHS (Filesystem Hierarchy Standard — Стандарт ієрархії файлової системи) — це офіційний документ, який регламентує розміщення каталогів та файлів певного типу в Linux-системах.
##### Роль стандарту в контексті файлових систем:
- Уніфікація: Завдяки FHS розробники ПЗ та системні адміністратори завжди знають, де шукати конфігурації, бінарні файли чи логи, незалежно від дистрибутива (Ubuntu, Fedora, Arch тощо).
- Прогнозованість: Забезпечує сумісність програм. Програми інсталюються у чітко визначені місця.
- Поділ даних: FHS чітко розділяє файли на статичні (що не змінюються без адміністратора, як-от /usr) та динамічні (що постійно змінюються, як-от /var).
##### Ключові каталоги згідно з FHS:
- /bin — основні утиліти командного рядка, необхідні для всіх користувачів.
- /boot — файли, необхідні для завантаження системи (ядро, інсталятор Grub).
- /etc — конфігураційні файли системи та програм.
- /home — особисті каталоги користувачів із їхніми даними та налаштуваннями.
- /var — змінні дані: логи (/var/log), бази даних, черги принтерів.
##### 3.Основні команди Linux для роботи з файлами та каталогами
- Створення
   - touch назва_файлу — створити порожній файл.
	- mkdir назва_папки — створити новий каталог.
- Переміщення та перейменування
   - mv шлях_звідки шлях_куди — перемістити файл або каталог.
	- mv старе_ім'я нове_ім'я — перейменувати файл або каталог.
- Копіювання
   - cp файл_джерело файл_копія — скопіювати файл.
	- cp -r папка_джерело папка_копія — скопіювати каталог разом із вмістом (рекурсивно).
- Видалення
  - rm назва_файлу — видалити файл.
  - rmdir назва_папки — видалити порожній каталог.
  - rm -rf назва_папки — видалити каталог з усім його вмістом без попереджень (використовувати обережно).
